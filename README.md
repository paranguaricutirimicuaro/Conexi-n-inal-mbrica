# Conexi-n-inal-mbrica
Con módulo bluetooth

El objetivo de este proyecto es implementar en nuestro Arduino un módulo Bluetooth, configurarlo mediante código y lograr su conexión con otro dispositivo para controlar el encendido y apagado de un LED de forma inalámbrica.
